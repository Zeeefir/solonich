# Локальная база и профили

В двух терминалах из этой папки:

```powershell
npm.cmd run server
```

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 5174 --strictPort
```

- Сайт: http://127.0.0.1:5174/
- Регистрация и вход: http://127.0.0.1:5174/profile
- Админка базы товаров: http://127.0.0.1:5174/admin
- Создание первого администратора: http://127.0.0.1:5174/setup

Для создания администратора откройте `data/admin-setup-code.txt`, скопируйте код в форму настройки и задайте свои имя, email и пароль. Код одноразовый; после настройки файл удаляется. Обычная регистрация создаёт покупателя и не даёт права изменять товары.

В админке нажмите «Добавить товар». Заполните названия и состав на RU/KZ/EN, вес, пищевую ценность, хранение, срок годности и путь к фото. Для фото поместите файл в `public/products` и укажите `/products/имя-файла.jpg`. Можно использовать HTTPS-ссылку. Нажмите «Сохранить». Можно также редактировать и удалять товары.

Данные хранятся в `data/solonich.sqlite`, каталог первоначально заполнен 12 существующими товарами. После этого JSON в исходниках используется только для первичного заполнения новой базы. Каталог сайта читает SQLite через сервер.

Для резервной копии остановите сервер и скопируйте папку `data`. Не публикуйте её в Git: там находятся учётные записи и сессии. Пароли сохраняются как хеши с солью, сессии — в HttpOnly cookie.

Это локальный сервис на вашем компьютере, без интернет-доступа. Подтверждение email и восстановление пароля через почту пока не подключены.

Проверка серверной части:

```powershell
node --test server/server.test.mjs
```
